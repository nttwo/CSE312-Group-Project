CSE 312 multiplayer browser game.

## Rules for all agents
1. Inspect the repository and relevant contracts first.
2. State the files you intend to change before editing.
3. Stay within the assigned task and ownership area.
4. Never silently change shared API or message contracts.
5. Do not rewrite another teammate's component.
6. Preserve working behavior and add regression tests.
7. Never hardcode secrets or commit credentials.
8. Do not commit, push, merge, or deploy automatically.
9. Report tests actually run and any failures.
10. Explain cross-component dependencies and blockers.
